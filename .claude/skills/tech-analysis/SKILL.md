---
name: tech-analysis
description: 銘柄コード(例 8058, 7203.T, AAPL。空白区切りで複数可)を受け取り、短期(日足)・中期(週足)・長期(月足)でテクニカル分析し、それぞれエントリータイミングかを判定する
argument-hint: <銘柄コード> [銘柄コード...]
---

対象: $ARGUMENTS (空白区切りで複数可。各コードについて 1〜3 を行う)

1. コードごとに次を実行して指標を取得する(数字だけのコードは自動で `.T` を付与)。複数コードなら Bash を並列で呼ぶ:
   `python "${CLAUDE_SKILL_DIR}/ta.py" <コード>`
2. 出力(移動平均と乖離・傾き、RSI、MACDヒストグラムの変化、BB、ストキャス、高安値、スイング安値、ATR、出来高比)をもとに以下の形式で日本語でまとめる:
   - 冒頭に結論表: | 時間軸 | 判定(❌/△/○/◎) | 一言 | エントリー目安(価格・条件・損切り) |
     - ◎: 今がエントリー好機。上昇トレンド+モメンタム好転(MACD GC直後等)+過熱なし(RSI<70・Stoch<80)+サポート近くで損切り幅が浅い、が全て揃う
     - ○: 買い方向だが条件待ち(押し目・ブレイク確認) / △: 様子見 / ❌: 見送り
   - 短期(日足)/中期(週足)/長期(月足)それぞれ: トレンド、モメンタム、サポート/レジスタンス、具体的なエントリー条件・損切り目安(ATR基準)
   - 末尾に「ファンダ・決算日程は未考慮、投資判断は自己責任」の一文
3. まとめを Markdown ファイルとして `${CLAUDE_SKILL_DIR}/../../../analysis/<YYYYMMDD>/<symbol>_<銘柄名>.md` に Write する(symbol は ta.py 出力の `symbol:`、銘柄名は見出しと同じ日本語名で空白やファイル名に使えない文字は除く、日付はデータ最終日)。先頭に `# <symbol> <銘柄名> テクニカル分析 (<日付>終値 <価格>)` の見出しを付ける。日付フォルダがなければ作る。同名ファイルがあれば上書き。
4. チャットには銘柄ごとに結論表と保存先パスだけを返す。取得に失敗したコードはエラー内容を一言添えてスキップする。
