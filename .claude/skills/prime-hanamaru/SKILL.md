上限: $ARGUMENTS (空なら 10)

◎の判定はすべて `screen.py` が機械的に行う。判定・除外・損切り・目標の数値は screen.py の出力をそのまま使い、独自に判定し直したり数値を計算し直したりしない。

1. 次を実行する(プライム約1550銘柄、1〜2分):
   `python -I "${CLAUDE_SKILL_DIR}/screen.py"`
   - 判定条件(日足 SMA25/75・週足 SMA13/26・月足 SMA12/24 ごと):
     - 基本: 上昇トレンド(短期線>中期線、両方上向き、終値>中期線) / MACD GC 3本以内 / RSI<70・Stoch<80 / 短期線まで2ATR以内
     - 精査: 5本で+3ATR超の急騰なし / 直近60本高値までの RR≥1.5(損切り=短期線-1ATR、高値更新中は免除) / 日足のみ出来高5/20日比≥0.7
   - 出力: 1行目に件数、続いて◎銘柄のTSV(列: symbol・銘柄名・終値・月足・週足・日足・詳細。月足〜日足は該当時間軸に◎。優先順に並んでいる)、`DROP` 行は基本条件を満たしたが精査で除外された銘柄と理由
2. ◎銘柄の上位から上限件数まで `python "${CLAUDE_SKILL_DIR}/../tech-analysis/ta.py" <symbol>` を並列実行し、/tech-analysis の手順 2〜3 の形式で `${CLAUDE_SKILL_DIR}/../../../analysis/<YYYYMMDD>/<symbol>_<銘柄名>.md` に Write する(銘柄名は screen.py の日本語名)。結論表の判定は、screen.py で◎になった時間軸を◎とし、それ以外の時間軸は /tech-analysis の基準(○/△/❌)で判定する。◎時間軸のエントリー目安には screen.py の損切り・目標をそのまま書く。
3. `${CLAUDE_SKILL_DIR}/../../../analysis/<YYYYMMDD>/prime_hanamaru.md` に Write する(日付は出力の last。日付フォルダがなければ作る):
   - `# プライム◎スクリーニング (<日付>)`
   - 1行目の件数
   - ◎銘柄の表: | symbol | 銘柄名 | 終値 | 月足 | 週足 | 日足 | 損切り | 目標(RR) | 分析ファイル |(月足・週足・日足は◎の時間軸だけ「◎」、他は空欄。損切り・目標は◎時間軸の値で、複数あれば「月足:… / 週足:…」と併記。上限外の銘柄は分析ファイル欄を「-」にする)
   - DROP 行の銘柄と理由(出力のまま)
   - 末尾に「ファンダ・決算日程は未考慮、投資判断は自己責任」の一文
4. チャットには◎銘柄の表と保存先パスだけを返す。◎が0件ならそのことを一言で伝える。
