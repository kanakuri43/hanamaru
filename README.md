# hanamaru 取扱説明書

日本株のテクニカル分析ツール。データは Yahoo Finance(日足5年分)から取得。

## 使い方

```
hanamaru ta <コード>...     個別銘柄の指標を表示し analysis/<日付>/<symbol>_<名前>.md に保存
hanamaru screen [上限]      プライム全銘柄を◎判定し <exeのフォルダ>/analysis/yyyy-MM-dd.html に保存してブラウザで開く
hanamaru                    引数なしは screen と同じ
```

- コードは `7203` のように数字だけでOK(自動で `.T` が付く)。
- 出力先 `analysis/` は実行したカレントディレクトリ配下。日付は最新の終値の日付。
- `screen [上限]` は先頭N銘柄だけ試す用(動作確認向け)。
- 環境変数
  - `ANTHROPIC_API_KEY` … 設定するとスクリーニングで週足◎の銘柄をAIが採点(未設定なら自動スキップ)
  - `STOCKS_PAR` … 同時取得数(既定24)。エラーが多いときは下げる

## 時間軸

日足・週足(ISO週)・月足を、日足データから作って同じロジックで判定する。
各足で使う移動平均(短期 / 中期)は下表。

| 足 | 短期線 | 中期線 |
|---|---|---|
| 日足 | SMA25 | SMA75 |
| 週足 | SMA13 | SMA26 |
| 月足 | SMA12 | SMA24 |

## `ta` の出力項目

| 項目 | 算出方法 |
|---|---|
| SMA | 直近N本の終値平均。「終値比」は終値÷SMA−1、「5本前」は5本前時点のSMAで上向き/下向きを判定 |
| RSI14 | Wilder方式の14本RSI。70以上=買われすぎ、30以下=売られすぎ |
| MACDヒストグラム | (EMA12−EMA26)とそのEMA9の差。前の本より大きければ「拡大」 |
| ボリンジャー20 | 20本平均 ±2σ(母標準偏差) |
| Stoch%K14 | (終値−14本安値)÷(14本高値−14本安値)×100。80以上=過熱、20以下=売られすぎ |
| N本 高値/安値 | 直近20/52/60本の最高値・最安値 |
| ATR14 | 14本の True Range(高安差・前日終値との差の最大)の単純平均。値幅の目安 |
| 出来高5日/20日比 | 直近5日平均出来高÷直近20日平均出来高。1超なら増加傾向 |

## `screen` の◎判定

足ごとに以下をすべて満たすと◎。1つでも外れれば対象外(足ごとに別判定)。

**基本条件**
1. 短期線 > 中期線 > (それぞれ5本前の値)、かつ短期線 > 5本前の短期線 …上昇トレンド
2. 終値 > 中期線
3. MACDヒストグラムが今日プラス、かつ直近3本のどこかで0以下 …ゴールデンクロス直後
4. RSI < 70 かつ Stoch < 80 …過熱していない
5. (終値−短期線)÷ATR ≦ 2 …短期線から離れすぎていない

**精査(該当したら除外)**
- 急騰: 5本で終値が +3ATR 超上昇
- 上値抵抗が近い: 直近60本高値(当日除く)が上にあり、RR < 1.5
- 出来高細り(日足のみ): 5日/20日比 < 0.7

**算出値**
- 損切り = 短期線 − 1ATR
- 目標 = 直近60本高値(終値が超えていれば「高値更新中」)
- RR = (目標−終値) ÷ (終値−損切り) 。利益見込み÷損失見込み

### 結果の見方

- 並び順: ◎の時間軸が多い順 → RRが大きい順。複数足が◎のときは「週足:…/日足:…」と併記。
- コメント(定型): 短期線との距離(<0.5ATR=押し目圏 / <1.2=適度 / それ以上=追いかけ注意)、RR(3以上=余地大 / 2以上=あり / 未満=限定的)、RSI65以上かStoch75以上なら「過熱気味」。
- 銘柄名のリンクは Yahoo!ファイナンスのチャートを開く。
- 条件が厳しいので、◎が0件の日も普通にある。

### AIスコア(週足◎のみ・100点満点)

数値だけを渡して Claude が採点。各項目は上限でクリップして合計する。

| 略称 | 項目 | 満点 |
|---|---|---|
| 押 | 押し目の質(短期線との距離、反発の形) | 25 |
| 余 | 上値余地(RR。52週高値の近くでも減点しない) | 20 |
| 出 | 出来高の傾向(5/20日比、上昇日と下落日の出来高差) | 20 |
| 熱 | 過熱感の無さ(RSI70超・Stoch85超で大きく減点) | 15 |
| 勢 | トレンドの強さ(MAの傾き、他の足も◎か) | 20 |

◎通過銘柄の平均が50点前後になるよう厳しめに採点する指示。コメントは初心者向けの2文。

配点の考え方(一般的な実証研究に基づく目安で、このツール自体でのバックテストはしていない):
- 勢: モメンタム(過去の上昇が続く傾向)は最も頑健とされる効果なので重めにする。
- 押: 上昇トレンド中の短期的な押し目は反発しやすい(短期リバーサル)。エントリー位置の良し悪しに直結するので最大配点にする。
- 余: 52週高値に近い銘柄はむしろ続伸しやすい(52週高値効果)。そのため高値への近さは減点せず、RRだけで評価する。
- 出: 出来高の効果は研究によって結論が割れるので、中程度にする。
- 熱: 押し目の質と同じ「伸びすぎ」を見ているので控えめにする。上昇トレンド中はRSI50〜65が普通なので、閾値は高めにする。

### AIチェックの仕組み

- **対象**: 週足が◎の銘柄だけ。月足・日足のみ◎の銘柄は対象外(表の該当セルは空欄)。
- **実行条件**: `ANTHROPIC_API_KEY` が設定されていること。未設定なら「スキップ」と表示して続行し、AIスコア・AIチェック欄は空になる。
- **モデル**: `claude-opus-5-5`(Anthropic Messages API)。同時4銘柄で並列実行。
- **AIに渡す情報**(銘柄ごとの数値のみ。ニュースやファンダは渡さない)
  - 週足のRSI・Stoch、短期線からの距離(ATR単位)、損切り、目標・RR(高値更新中ならその旨)
  - 出来高の推移(直近6週の日平均、5日÷20日、20日÷60日、上昇日÷下落日)
  - 週足終値の直近12週、52週高値・安値との距離、週足SMA13/26の5週間の変化率
  - 他に◎になっている時間軸
- **返答**: 5項目の点数とコメントのJSON。返答中の `{ ... }` を取り出して読み取る。
- **点数の扱い**: 各項目を0〜満点の範囲に収め(超過は満点、負は0)、プログラム側で合計する。AIの足し算ミスや配点超過は反映されない。
- **失敗時**: JSON崩れは1回だけ再試行。それでも失敗、またはAPIエラー(レート制限など)の場合はスコア「-」、コメントに「AIチェック不可: <エラー>」と出る。
- **表示**: HTMLの「AIスコア」列に合計と内訳(例: 押20 余15 出18 熱9 勢7)、「AIチェック」列にコメント。
- **注意**: `ta` コマンドではAIは使わない。AIの採点は参考値で、◎判定自体(機械判定)には影響しない。実行ごとに結果が多少ぶれる。API利用料は◎銘柄数ぶん発生する。

## 注意

- ファンダメンタルズ・決算日程は考慮していない。投資判断は自己責任。
- Yahooの非公式APIを使用。レート制限で全件失敗したら時間をおいて再実行。
- プライム銘柄一覧はJPXの公開Excelから毎回取得。
